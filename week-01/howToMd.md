## 1. Headings

# Main Title (Heading 1)
## Chapter / Topic (Heading 2)
### Subtopic (Heading 3)

## 2. Text Formatting

Bold: **bold text** or __bold test__
Italic: *italic text* or _italic text_
StrikeThrough: ~~strikethrough~~

## 3. Lists

### Bullet Points

* Item one
* Item two

### Numbered List

1. First Step
2. Second Step

### Tasks List

- [x] Completed Task
- [ ] Pending Task

## 4. Links and Images

Links: [Link Text](https://example.com)
Images: ![Alt Text for Image](image-path-or-url.png)

## 5. Code and Quotes

Blockquote: Use > to highlight quotes or important notes; 
> This is a blockquote, great for callouts or summaries.

Inline Code: Wrap code snippets in single backticks: `print("Hello")`

Code Blocks: Use triple backticks for multi-line code blocks:
```python

    print("World")
