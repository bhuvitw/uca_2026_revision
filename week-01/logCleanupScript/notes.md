**Problem Statement**
You are managing a high-traffic web server that generates daily log files in a directory called `/var/log/app/`. Over time, these files take up too much disk space.

Your task is to write a shell command using `find` and `xargs` to compress all .log files that are older than 30 days using `gzip`.

**Requirements**
File Selection: Only target files ending in .log that haven't been modified in the last 30 days.
Handling Spaces: Some logs generated by third-party plugins contain spaces in their names (e.g., api error.log). Your command must not break or error out when encountering spaces.
Performance Optimization: There are tens of thousands of log files. Instead of compressing them one by one, you must configure xargs to process up to 4 files simultaneously in parallel to speed up the execution.


find
----
find <starting-point> <expression>

-type f
→ regular files

-type d
→ directories

-name "pattern"
→ match filename using shell-style pattern

Examples:
find . -type f
find . -name "*.txt"
find /var/log/app -type f -name "*.log"
